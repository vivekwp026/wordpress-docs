Connection Setup

To begin synchronizing data between WooCommerce and Bagisto, you must first establish a secure connection between the two systems.

Obtaining Bagisto API Credentials

Before generating an API token, you must first configure the Bagisto API on your Bagisto store. Follow the Bagisto API Setup Guide to enable and configure the API. Once the API setup is complete, you can proceed with generating the API token from your Bagisto admin panel.

  1. Log in to your Bagisto Admin Panel.
  2. Navigate to Integration > Tokens.

  1. Click the Create Integration button.

  2. Fill in the required integration details:

    • Name
    • Description (optional)
    • Assign User
    • Permission Type (All or Custom)
    • If Custom is selected, choose the required permissions from the Access Control section.

  3. Click Save to create the integration.

  4. In the Token Settings section, configure the token options such as:

    • Validity (Never Expires or Expiry Date)
    • Rate Limit (Per Minute)
    • Rate Limit (Per Day)
    • IP Allowlist (Optional)

  5. Click Generate Token. A confirmation dialog will appear informing you that the plaintext token will be shown only once.

  6. Click Agree to generate the access token.

  7. Copy the generated API token immediately, as it will not be displayed again after leaving the page.

  8. Keep the following information safe for future API authentication:

    • Bagisto Site URL
    • Generated API Token

Connecting WooCommerce to Bagisto

Once you have the API credentials, follow these steps in your WooCommerce dashboard:

  1. Navigate to WC to Bagisto > Connection in the WordPress sidebar.
  2. You will see the Connection Settings page where you must provide your Bagisto details.

Configuration Fields

  • Bagisto Site URL: Enter the base URL of your Bagisto storefront (e.g., https://your-bagisto-store.com). Ensure it starts with http:// or https:// and does not include a trailing slash.
  • Bagisto API Token: Paste the API token you generated from the Bagisto admin panel.
  • Test Connection: Before saving, it is highly recommended to click the Test Connection button to verify that WooCommerce can communicate with Bagisto using the provided credentials.

Saving the Connection

After a successful test, click the Save Connection button. The plugin will securely store your credentials and unlock the other configuration menus such as Settings, Bulk Sync, and Logs.

[!NOTE] If the connection fails, verify that your Bagisto URL is correct, the API token is active, and there are no firewall or server restrictions blocking requests from your WordPress server.
