Troubleshooting & FAQ

If you encounter issues while configuring or using the WooCommerce to Bagisto Connector, consult this guide for common solutions.

Frequently Asked Questions

1. The connection test fails. What should I do?

Verify the following:

  • Ensure your Bagisto Site URL is correct and does not have a trailing slash.
  • Ensure the API Token is valid, active, and has the necessary permissions in Bagisto.
  • Check if your server firewall or security plugins are blocking outbound cURL requests.

2. Products are not syncing during Bulk Sync. Why?

Bulk Sync relies on WordPress background cron jobs.

  • Ensure that WP_CRON is functioning correctly on your server.
  • Verify that you have synced Categories and Attributes before attempting to sync Products.

3. Orders are failing to sync.

Orders require the associated products and customers to exist in Bagisto first. If a product in the order hasn't been synced, the order sync will fail. Sync your Customers and Products first.

4. How do I stop an ongoing Bulk Sync?

The bulk sync runs in the background. While there isn't a direct "stop" button, you can manage the queue using a WP Cron manager plugin, or clear the queue directly from the database if absolutely necessary.

Common Error Log Messages

  • "Not connected with Bagisto. Please create connection..."
    • Solution: You haven't successfully saved your connection settings. Go to the Connection tab and authenticate.
  • "No user roles created in the Bagisto..."
    • Solution: You must create at least one user role/customer group in your Bagisto admin panel and assign it as the default in the plugin's Settings.
  • "Search string can not be empty."
    • Solution: When using the specific ID exclusion or inclusion filters, ensure you are formatting the input correctly.
