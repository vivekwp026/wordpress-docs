Why the Printify Connector suits a WooCommerce multi vendor marketplace

Give the admin and every vendor their own Printify connection, and keep print on demand products, orders, statuses and tracking in step without copying anything by hand.

Automatic Printify Sync
Printify webhooks keep your WooCommerce store current on their own, importing new products, updating changed ones and moving deleted ones to Trash, based on the rules you choose.
Guided Setup Wizard
A four step wizard takes the admin and every vendor from a Printify API token to a connected shop with product and order defaults, with no developer needed.
Vendor Printify Accounts
Every marketplace vendor connects their own Printify shop from the vendor dashboard, so imported products and exported orders always stay with the right seller.
Import Print on Demand Products
Pull simple and variable Printify products into WooCommerce with titles, descriptions, prices, weights, variations and images, created safely in the background.
Export Orders to Printify
Send orders containing Printify products for fulfilment automatically at checkout or in bulk, with each vendor sending only their own Printify items.
Import Printify Orders
Bring orders placed directly in Printify into the store with Printify totals, and import any missing products with them so every line stays linked.
Order Status and Tracking Sync
Map each Printify order status to a WooCommerce status, and give customers a shipping note with the tracking number the moment Printify ships.
Exclude Products from Sync
Keep chosen store products untouched by updates, or block specific Printify products from ever being imported, with one list for each case.
Webhook Events Log
See every product and order update Printify sends, whether it completed, is waiting or failed, and a plain explanation of what changed in the store.
Printify Connector Comparison
See how the Printify Connector compares with the official Printify WooCommerce integration and Dokan's Printful module on vendor accounts, product and order sync, support and licensing.

What's New in v2.0.0

  • Guided Setup Wizards — Four step setup for the admin and every vendor, from Printify API token to connected shop with product and order defaults. Setup Wizard Guide →
  • Update from Printify — Refresh products already in your store, and choose exactly which fields an update may replace: name, description, price, weight, variations and images. Imported Products Guide →
  • Background Product and Image Import — Products are created and images downloaded in the background, with live progress, stop and retry, and a choice of importing the first five images with each product. Import Guide →
  • Automatic Sync with Printify Webhooks — Products created, changed or deleted in Printify are imported, updated or moved to Trash automatically, and every update is listed on the Webhook Events page. Webhook Events Guide →
  • Exclude Products — Keep chosen store products untouched by updates, and stop specific Printify products from ever being imported. Exclude Products Guide →
  • Order Import and Status Mapping — Bring orders placed in Printify into the store with Printify totals, and map every Printify order status to a WooCommerce status. Sync Settings Guide →
  • Shipping Tracking for Customers — When Printify ships an order, the customer gets an order note with the tracking number and link, with an option to send order emails for Printify updates. Manage Orders Guide →
  • Correct Multi Vendor Order Export — Orders with products from several sellers now send only the exporting seller's own Printify items, and a refused order shows Printify's reason. Export Orders Guide →
  • Redesigned Admin and Vendor Screens — A new sidebar layout with breadcrumbs, help tips, confirmation dialogs and better responsiveness, identical for the admin and vendors. Vendor Dashboard Guide →
  • WordPress 7.1 and WooCommerce 11.0 Compatible — Tested with WordPress 7.1, WooCommerce 11.0 and Marketplace 6.8, with HPOS and Cart and Checkout blocks compatibility declared. System Requirements →
