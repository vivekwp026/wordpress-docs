Features

Connection

  • Connect a Printify shop using a Printify Personal Access Token
  • Separate Printify connection for the admin and for every vendor
  • Guided four step setup wizard for the admin and for vendors
  • Connection status card showing the shop, shop ID, masked token, products imported and live update status
  • Switch to another shop or token at any time, or disconnect cleanly
  • Built-in guide showing where to generate the API token in Printify

Products

  • Import simple and variable products from Printify
  • Product name, description, price, SKU, weight, attributes, variations and images are imported
  • Products created in the background, safe to leave the page while it runs
  • Choose to publish imported products straight away or keep them as drafts
  • Assign every imported product to a default WooCommerce category
  • Import images with the product (first five at once) or entirely in the background
  • Update from Printify refreshes products already in the store
  • Choose which fields an update may replace: name, description, price, weight, variations and images
  • Bulk exclude, include or permanently delete imported products

Orders

  • Export orders that contain Printify products to Printify for fulfilment
  • Automatic export at checkout, or manual export in bulk
  • Multi vendor aware: each seller sends only their own Printify items
  • Clear reasons shown when Printify refuses an order
  • Import orders placed directly in Printify, using Printify's totals
  • Import missing products together with an imported order
  • Map every Printify order status to a WooCommerce status
  • Customer order note with the tracking number and link when Printify ships
  • Choose whether order emails are sent for Printify driven updates

Automatic sync

  • Printify webhooks registered automatically when a shop is connected
  • Automatic product import, update and deletion, each switched on separately
  • Automatic order import and order status sync
  • Webhook Events log with status and a explanation of each update

Exclusions

  • Stop chosen store products from being updated by Printify
  • Stop chosen Printify products from ever being imported

Compatibility

  • WooCommerce High Performance Order Storage (HPOS)
  • WooCommerce Cart and Checkout blocks
  • Translation ready
