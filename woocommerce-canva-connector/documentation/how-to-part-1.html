Installation & Basic Setup

This guide walks you through the initial steps: system requirements, downloading, uploading, activating, and licensing the WooCommerce Canva Connector plugin on your WordPress store.

System Requirements

Before getting started, make sure your server environment meets the following requirements:

RequirementMinimum / Recommended Version
WordPress5.8 or higher
WooCommerce6.0 or higher
PHP7.4, 8.0, 8.1, or 8.2
SSL Certificate (HTTPS)Required for Canva OAuth and REST API communication
Canva AccountFree or Pro Canva account with access to Developer Portal

Step 1: Download & Upload Plugin

  • What to click: In your WordPress Admin Dashboard, navigate to Plugins > Add New Plugin and click the Upload Plugin button at the top.
  • What to do: Click Choose File, select the woocommerce-canva-connector.zip file downloaded from your Webkul account, and click Install Now.
  • Expected result: WordPress unpacks and installs the plugin files on your server.

Step 2: Activate the Plugin

  • What to click: On the installation status screen, click Activate Plugin (or go to Plugins > Installed Plugins and locate WooCommerce Canva Connector).
  • What to do: Ensure the plugin status shows as active.
  • Expected result: The plugin is enabled, and the Webkul WC Addons menu appears in your WordPress admin sidebar.

Step 3: Activate License Key

  • What to click: In the WordPress admin menu, navigate to Webkul WC Addons > License.
  • What to enter: Enter your purchase code / license key in the field provided and click Save & Activate.
  • Expected result: Your license is validated, enabling product updates and support.

Step 4: Locate Canva Connect Settings

  • What to click: Navigate to Webkul WC Addons > Canva Connect (or Settings > Canva Connect).
  • What you will see: The configuration dashboard displaying input fields for App ID, Client ID, Client Secret, Disable CORS Headers, and the automatically generated Redirect URI and Return URL.
  • Expected result: You are ready to connect your store with your Canva Developer Portal app.
